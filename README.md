# Gravity Flip 🌌

A fast-paced, minimalist 2D arcade platformer built for the browser using modern web technologies and the HTML5 Canvas API. Instead of traditional jumping, players navigate dynamic courses by inverting gravity on command, traversing between the floor and ceiling while dodging procedural hazards.

🎮 **Live Demo:** [gravity-flip-games.netlify.app](https://gravity-flip-games.netlify.app/)

---

## 🕹️ Gameplay & Controls

* **Mechanic:** Invert gravitational pull instantaneously. You must land on a solid surface before changing vertical direction again.
* **Controls:** 
  * `Spacebar` / `Up Arrow` / `Left Click` — Flip gravity
  * `Touch Tap` — Flip gravity (Mobile devices)
* **Objective:** Travel as far as possible without colliding with obstacles, gaps, or ceiling/floor hazards to achieve a high score.

---

## ✨ Features

* **Instant Physics Loop:** Smooth, high-performance 60 FPS gameplay powered by HTML5 Canvas.
* **Minimalist Aesthetics:** High-contrast visuals paired with clean animations and hitboxes.
* **Responsive Layout:** Automatically scales across desktop monitors, tablets, and smartphones.
* **Progressive Difficulty:** Dynamic scaling increases speed and obstacle density over time.
* **Zero Dependencies:** Pure vanilla web stack with no bloated libraries or heavy external assets.

---

## 🛠️ Built With

* **HTML5 Canvas** — Graphic rendering and sprite animations
* **CSS3** — Viewport styling, UI layering, and responsive containers
* **Vanilla JavaScript (ES6+)** — Core game loop, collision detection, and physics engine
* **Netlify** — Production hosting and continuous deployment
